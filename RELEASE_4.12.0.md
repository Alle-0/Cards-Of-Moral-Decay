# Release 4.12.0

## What's New
- **Desktop Support**: Added full desktop experience with sidebar navigation for web version
- **Theme Selection**: New theme selection modal allowing users to customize app appearance
- **UI Overhaul**: Major improvements to user interface components for better responsiveness and user experience
- **Enhanced Navigation**: Improved navigation system with desktop-specific features
- **Security Enhancement**: Hidden Firebase API key for better security

## Improvements
- Optimized GameScreen, ShopScreen, and SettingsScreen for better performance
- Enhanced Premium components (buttons, modals, toggles) with improved styling
- Better avatar and frame selection experience
- Improved lobby and personalization screens
- Enhanced drag scroll functionality for web

## Bug Fixes
- Various UI fixes and optimizations across components
- Fixed responsiveness issues on different screen sizes

## Technical Changes
- Added DesktopSidebar component for web navigation
- Updated multiple components for desktop compatibility
- Improved context management in GameContext
- Enhanced web-specific hooks and utilities
